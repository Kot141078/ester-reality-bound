# L4 Glitch / Research Quarantine Stack v0.1

This subtree holds the **normative** and **visibility-facing** side of the glitch-stack package set.

It is intentionally split into two package groups:

1. **Core Specification**
   - L4 collision
   - research quarantine
   - witness discipline
   - challenge / review
   - state transition and status algebra

2. **Graph / Visibility Companion**
   - cinematic walkthrough as bounded visibility
   - graph grammar
   - rendering discipline
   - visual anti-laundering rules

## Reading intention

The markdown files remain the canonical working layer.
The PDF files remain the reader-facing packaged layer.

This subtree is meant to preserve both:
- source-level textual precision
- and human-readable packaged access

without collapsing the two.

## Boundary

This repository hosts the **normative / reality-bound** side.

The **implementation / code-bridge** side lives in:

- `ester-clean-code`
- `docs/architecture/glitch-stack/`
